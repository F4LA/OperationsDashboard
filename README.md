# Operations Dashboard

A single central view of every Rock in a sprint (Sprint → Rock → Project → Milestone → Task) for Strong Standard, replacing Asana for Rock/sprint execution. Built from the approved spec at [`/docs/spec.md`](docs/spec.md); every setup and ambiguity-resolution call is logged in [`/docs/decision-log.md`](docs/decision-log.md). We are currently in **Phase 0 — repo, scaffold, and reference docs only**: no date engine or dashboard logic has been written yet.
